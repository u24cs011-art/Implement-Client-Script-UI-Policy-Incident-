# User Guide

## Purpose

This guide explains how an Incident user experiences the configured form behavior.

## Steps

1. Open the Incident form.
2. Enter the required Incident information.
3. Change the configured field to trigger the UI Policy.
4. Observe the mandatory/read-only/visibility change.
5. Enter the required information.
6. Attempt to submit the form.
7. Test the validation behavior using an invalid input.
8. Correct the input and submit again.

## Expected User Experience

The user receives immediate visual feedback from the form and is prevented from submitting data that violates the configured client-side validation rule.
