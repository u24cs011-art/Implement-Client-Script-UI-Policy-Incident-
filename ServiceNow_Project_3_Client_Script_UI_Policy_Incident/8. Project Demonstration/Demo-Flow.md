# Demo Flow

```text
1. Project Title
      ↓
2. Problem Statement
      ↓
3. ServiceNow Incident Table
      ↓
4. UI Policy Configuration
      ↓
5. UI Policy Action
      ↓
6. Client Script Configuration
      ↓
7. Live Form Behavior
      ↓
8. Invalid Input Validation
      ↓
9. Correct Input + Successful Submission
      ↓
10. Test Results
      ↓
11. Conclusion
```

## Suggested Demo Duration

5–8 minutes.
