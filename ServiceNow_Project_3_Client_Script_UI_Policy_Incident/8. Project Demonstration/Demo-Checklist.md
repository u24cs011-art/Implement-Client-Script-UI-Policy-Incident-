# Demo Checklist

Before recording:

- [ ] ServiceNow instance is accessible.
- [ ] Incident table opens correctly.
- [ ] UI Policies are active.
- [ ] UI Policy Actions are configured.
- [ ] Client Scripts are active.
- [ ] Test data is ready.
- [ ] Browser tabs are organized.
- [ ] No credentials are visible.
- [ ] Screen recording is working.
- [ ] Voice/audio is clear.
- [ ] Test cases are completed.
- [ ] Final result is documented.
