# Functional Requirements

## FR-01 – Incident Form Configuration

The system shall allow administrators to configure the Incident form.

## FR-02 – UI Policy

The administrator shall create UI Policies on the Incident table.

## FR-03 – Mandatory Field

The system shall make a selected field mandatory when the defined condition is true.

## FR-04 – Read-Only Field

The system shall make a selected field read-only when the defined condition is true.

## FR-05 – Visibility

The system shall show or hide a selected field according to the UI Policy condition.

## FR-06 – Client Script

The system shall execute client-side JavaScript when the configured form event occurs.

## FR-07 – Validation

The Client Script shall validate user input and prevent submission when the validation rule fails.

## FR-08 – Form Reset

When a condition becomes false, fields shall return to their configured normal behavior where appropriate.

## FR-09 – Documentation

The completed configuration shall be documented with screenshots and explanations.
