# Acceptance Criteria

- [ ] UI Policy activates when its condition becomes true.
- [ ] UI Policy makes the selected field mandatory/read-only/visible as designed.
- [ ] UI Policy reverses behavior correctly when its condition becomes false.
- [ ] Client Script runs on the intended form event.
- [ ] `g_form` methods modify the intended field.
- [ ] Invalid input is rejected where validation is configured.
- [ ] Valid input can be submitted successfully.
- [ ] No browser console errors are produced by the project scripts.
- [ ] Screenshots demonstrate the configured behavior.
