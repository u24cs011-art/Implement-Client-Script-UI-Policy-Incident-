# Non-Functional Requirements

## NFR-01 – Usability

The form behavior should be easy for Incident users to understand.

## NFR-02 – Performance

Client-side scripts should execute quickly and avoid unnecessary processing.

## NFR-03 – Maintainability

Scripts should be short, readable, and clearly commented.

## NFR-04 – Security

No credentials or sensitive instance information shall be stored in the repository.

## NFR-05 – Compatibility

The configuration should be tested in the target ServiceNow instance and supported UI experience used by the project.

## NFR-06 – Reliability

The configured rules should produce consistent results for the same input conditions.
