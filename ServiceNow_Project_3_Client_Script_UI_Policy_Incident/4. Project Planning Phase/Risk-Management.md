# Risk Management

| Risk | Impact | Mitigation |
|---|---|---|
| Wrong field name used in script | High | Verify field name in ServiceNow dictionary/form |
| UI Policy condition incorrect | High | Test both true and false conditions |
| Client Script not triggered | Medium | Verify Type, Table, Field, and Active settings |
| Script error | High | Check browser console and ServiceNow logs where applicable |
| Configuration differs between instances | Medium | Document exact field values and instance version |
| Sensitive information committed | High | Review repository before publishing |
